# 案例｜教学认证类：工程教育认证毕业要求达成度自评

## 真实场景

专业负责人正在准备第二轮工程教育认证申请，需要为支撑毕业要求指标点 2.3 与 5.2 写一份**达成度自评说明**。难点：表述要"持续改进"导向，证据要可追溯，**绝不能用"全国顶尖"这类绝对化词语**——评审专家会逐字挑。

## 输入

| 字段 | 值 |
| --- | --- |
| 学院 / 部门名称 | 机电工程学院（机械工程专业） |
| 材料类型 | 🎓 教学认证类 |
| 风格 | 客观分析 |
| 问题 / 主题 | 机械工程专业工程教育认证自评报告——毕业要求 2.3 与 5.2 达成情况 |
| 补充背景 | 本专业第二轮工程教育认证申请已受理，重点支撑指标点 2.3（工程问题表达与求解）和 5.2（现代工具使用）的达成度证据。 |

## 喂给 AI 后的输出示例

**机械工程专业工程教育认证自评报告——毕业要求 2.3 与 5.2 达成情况**

**一、基本情况**

机械工程专业自首轮工程教育认证通过以来，持续围绕成果导向（OBE）理念优化课程体系。本次自评聚焦毕业要求 2.3（能够正确表达和分解复杂工程问题，并通过文献研究分析其本质）和毕业要求 5.2（能够针对复杂工程问题，选择与使用恰当的工程模拟与仿真工具）。两条指标点分别由 5 门核心专业课程进行支撑，覆盖大三上学期至大四上学期。

**二、建设成效**

近三届毕业生数据显示，毕业要求 2.3 达成度在 0.74–0.78 区间，毕业要求 5.2 达成度在 0.71–0.76 区间，均高于专业设定的 0.65 合格阈值，呈现稳中有升趋势。课程层面，支撑 2.3 的核心课程已完成 2 轮课程目标修订，明确"问题表达—文献检索—问题分解"三段式评价点；支撑 5.2 的核心课程引入仿真平台过程性作业，作业成绩与教学目标的对应关系已在课程大纲中显化。

**三、存在问题**

回顾两个指标点的支撑过程，仍存在以下不足。一是不同课程对"复杂工程问题"内涵的边界界定不完全一致，导致跨课程之间的评价口径存在差异；二是文献检索与综述能力的过程性评价主要依赖任课教师主观判断，缺少结构化评分细则；三是工程仿真工具的使用普及与"会用"之间仍有差距，部分学生作业表现为"工具会用、问题理解不深"。

**四、改进措施**

为持续提升两个指标点的达成质量，专业层面将采取以下改进举措。一是组织 2 次专业课程"复杂工程问题"内涵研讨，统一各支撑课程的评价口径；二是会同图书馆开设面向大三学生的文献检索专项工作坊，并配套开发结构化的文献检索评分量表；三是在课程层面将"工具使用"与"问题理解"分列评分，仿真类作业评价权重向"问题理解与方法选择合理性"倾斜；四是建立专业层面的达成度年度复盘机制，将每年自评结果用于下一轮课程大纲修订。
