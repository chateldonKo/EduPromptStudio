# EduPromptStudio 案例库

每个案例展示一类高校公文从「真实场景」到「Prompt」再到「AI 输出」的完整链路，便于：

- 新用户快速判断这个工具是否对自己有用
- 老用户参考别人的输入怎么写更出活
- 搜索引擎收录长尾内容（每条案例都是独立页面）

> 所有案例都是脱敏 + 改写的虚构示例，仅用于演示工具用法。

## 想贡献你自己的案例？

只要把案例文件按照模板放进 `docs/cases/`，并在本页表格里追加一行即可。
可以匿名、可以脱敏，只要场景真实、Prompt 真用过、输出确实可用就行。

详见 [CONTRIBUTING.md](../../CONTRIBUTING.md)。
