# 案例｜方案类：师德师风专题学习实施方案

## 真实场景

学校发文要求各学院在一个月内开展师德师风专题学习。学院党委办公室需要写一份**院级实施方案**——既要落实上级精神，又要结合本院学科特点，还要有具体的时间节点和责任分工。

## 输入

| 字段 | 值 |
| --- | --- |
| 学院 / 部门名称 | 教育学院 |
| 材料类型 | 📐 方案类 |
| 风格 | 正式稳妥 |
| 问题 / 主题 | 学院师德师风专题学习实施方案 |
| 补充背景 | 落实上级师德师风建设要求，组织教职工开展为期一个月的专题学习。学习内容包括师德规范学习、典型案例研讨、师风承诺签订、专题民主生活会等环节。 |

## 喂给 AI 后的输出示例

**教育学院关于开展 2026 年师德师风专题学习的实施方案**

**一、背景与目标**

为深入贯彻教育部及学校关于加强新时代高校师德师风建设的工作要求，进一步压实师德建设主体责任，引导教职工将师德规范内化为职业自觉，结合本院教师教育类专业育人特点，决定于 2026 年 3 月在全院范围内开展为期一个月的师德师风专题学习。通过本次学习，使全体教职工对师德规范的具体内涵和负面清单边界形成清晰、统一的理解，并形成可执行、可检查、可问责的院系层面落实路径。

**二、工作内容**

本次专题学习设置四个模块：一是师德规范学习，组织教职工集中研读《新时代高校教师职业行为十项准则》和学校《师德失范行为处理办法》；二是典型案例研讨，结合教育部及兄弟院校公开通报的师德失范案例，按教研室分组开展案例剖析；三是师风承诺签订，每位教职工本人对照本岗位职责，签署个人师风承诺书；四是专题民主生活会，以教研室为单位开展批评与自我批评。

**三、实施步骤**

学习活动分四个阶段推进。第一阶段（第 1 周）为动员部署阶段，召开全院教职工大会，统一思想、明确分工；第二阶段（第 2 周）为集中学习阶段，以教研室为单位开展两次集中研读和一次专题学习简报撰写；第三阶段（第 3 周）为案例研讨与承诺签订阶段，组织典型案例剖析并完成全院教职工师风承诺书归档；第四阶段（第 4 周）为总结提升阶段，召开专题民主生活会，并形成本院专项报告。

**四、保障措施**

一是加强组织领导，由学院党委书记任组长，分管教学和学生工作的副院长任副组长，党委办公室负责日常协调与材料归档；二是明确责任分工，各教研室主任为本教研室专题学习第一责任人，负责本教研室成员的全过程参与；三是强化督导检查，党委办公室对各教研室学习开展情况进行过程性记录，每周以简报形式向党政联席会通报进度；四是严格成果运用，专题学习参与情况将作为本年度师德考核、岗位聘任、评奖评优的重要依据。
